# Debugt issues

Bug reports and feature requests for [Debugt](https://marketplace.visualstudio.com/items?itemName=debugt.debugt-extension),
the VS Code extension for debugging multi-service Node projects.

Debugt's source is private. This repository holds no code; it exists so anyone can report a
problem or ask for something.

## Reporting

[Open an issue](https://github.com/debugxt/debugt-issues/issues/new/choose) and pick a form:

- **Bug report**: something doesn't work, or works differently from what you expected.
- **Feature request**: something Debugt should do and doesn't.
- **License or plan**: activating, renewing or releasing a license, or what a plan allows.

Before opening one, search the [existing issues](https://github.com/debugxt/debugt-issues/issues?q=is%3Aissue);
a thumbs-up on an existing issue counts for more than a duplicate.

### What helps

- The Debugt version (Extensions view → Debugt) and VS Code version (Help → About).
- Steps that make it happen, starting from a fresh window if you can.
- The canvas console log for the day it happened:
  `~/.debugt/projects/<project>/console/<date>.jsonl`. Trim it to the relevant lines and remove
  anything private.

**Never paste a license key** into an issue. The first few characters are enough to find it.

## Security

Please don't report vulnerabilities here. Use
[private vulnerability reporting](https://github.com/debugxt/debugt-issues/security/advisories/new)
instead.
